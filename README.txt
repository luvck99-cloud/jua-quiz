사랑하는 주아와 퀴즈놀이 - 웹앱

실행 방법
1. index.html 파일을 더블클릭하면 PC 웹브라우저에서 실행됩니다.
2. 휴대폰에서 홈 화면 아이콘으로 사용하려면 인터넷에 공개 배포(예: GitHub Pages, Netlify 등)해야 합니다.
3. 기록은 브라우저의 localStorage에 저장되므로 같은 기기·브라우저에서 유지됩니다.

현재 포함 기능
- 레벨 1~50 전체 선택 가능, 레벨당 20문제
- 영어, 수학, 과학, 상식, 맞춤법, 띄어쓰기 문제 유형
- 시간 제한 없음
- 애매한 문제 표시 및 모음
- 틀린 문제 모음 및 다시 풀기
- 정답/도전 기록 저장

참고
문제는 코드가 생성하는 방식이며, 초안 버전입니다. 특히 맞춤법·띄어쓰기 및 과학/상식 문항은 실제 사용 전에 보호자와 함께 검토하는 것을 권장합니다.
